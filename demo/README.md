# 재생 데모 자료

`python -m dart_review demo`가 쓰는 자료다. 인증키, Ollama, 네트워크 없이 대표 질문 5개(SCOPE 2절)를 실제 코드로 처리한다.

- `opendart/`: 다섯 질문이 읽는 OpenDART 재무제표 응답 6개. 응답 캐시와 같은 구조다. **대상 계정 6개(매출액, 영업이익, 당기순이익, 영업활동현금흐름, 자산총계, 부채총계)의 행만 남겼다**(원본 1,012행 중 73행). 표준계정ID나 알려진 계정명으로 고른다.
- `model_replies.json`: 교차 확인 실행(`eval/3-0b_2026-10-08/crosscheck_dev/`, 프롬프트 `reading-v2`, 기준 날짜 2026-10-08)에서 gpt-oss:20b가 낸 해석이다. 그때 받은 메시지와 스키마의 SHA-256도 함께 있다. 재생할 때 지금 만든 메시지나 스키마가 기록과 다르거나, 프롬프트 버전이 다르면 멈춘다. 처음 녹화는 `reading-v1` 실행에서 했고, 3-0b에서 다시 녹화했다.
- 만드는 법: `python scripts/build_demo_fixtures.py <crosscheck 실행 폴더>` (로컬 캐시 필요). 이 스크립트는 몇 가지를 확인하고, 하나라도 어긋나면 실패한다.
  - 실행 폴더가 지금 프롬프트·스키마로 만든 것인지(`run.json`의 계약 해시)
  - 축소본으로 만든 답이 기록된 실행의 답과 글자까지 같은지

**재배포 조건:** OpenDART 응답의 재배포 조건은 아직 확인하지 않았다. 첫 외부 전송 전에 확인한다(로드맵 3-4). 그래서 원본 응답은 저장소에 넣지 않고(`cache/`는 git 제외), 데모에 필요한 계정 행만 넣었다. 공개 전에 조건을 확인하고, 허용되지 않으면 이 폴더를 빼거나 대체한다.
