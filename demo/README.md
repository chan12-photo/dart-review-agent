# 재생 데모 자료

`python -m dart_review demo`가 쓰는 자료다. 인증키, Ollama, 네트워크 없이 대표 질문 5개(SCOPE 2절)를 실제 코드로 처리한다.

- `opendart/`: 다섯 질문이 읽는 OpenDART 재무제표 응답 6개. 응답 캐시와 같은 구조다. **대상 계정 6개(매출액, 영업이익, 당기순이익, 영업활동현금흐름, 자산총계, 부채총계)의 행만 남겼다**(원본 1,012행 중 73행). 표준계정ID나 알려진 계정명으로 고른다.
- `model_replies.json`: 교차 확인 실행(`eval/reading-v4_2026-10-08/crosscheck_dev/`, 프롬프트 `reading-v4`, 기준 날짜 2026-10-08)에서 gpt-oss:20b가 낸 해석이다. 그때 받은 메시지와 스키마의 SHA-256도 함께 있다. 재생할 때 지금 만든 메시지나 스키마가 기록과 다르거나, 프롬프트 버전이 다르면 멈춘다. 녹화는 `reading-v1`에서 처음 했고, `reading-v2`(3-0b)와 `reading-v4`에서 다시 했다.
- 만드는 법: `python scripts/build_demo_fixtures.py <crosscheck 실행 폴더>` (로컬 캐시 필요). 이 스크립트는 몇 가지를 확인하고, 하나라도 어긋나면 실패한다.
  - 실행 폴더가 지금 프롬프트·스키마로 만든 것인지(`run.json`의 계약 해시)
  - 축소본으로 만든 답이 기록된 실행의 답과 글자까지 같은지

**데이터 출처: 금융감독원 OpenDART (opendart.fss.or.kr).**

**재배포:** 공개 전에 OpenDART 이용약관을 확인했다. 공시 데이터의 재배포를 금지하는 조항은 없었다([공개 전 점검](../docs/PUBLICATION_CHECK.ko.md) 2절). 그래도 원본 응답 전체는 넣지 않는다(`cache/`는 git 제외). 이 폴더에는 데모에 필요한 계정 행만 출처를 밝혀 넣었다.
