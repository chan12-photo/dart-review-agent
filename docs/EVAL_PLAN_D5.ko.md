# D5 계획: D4 결함을 고친 제품을 새 회사 문서로 다시 잰다 (초안, 2026-10-20)

- 상태: **계획 초안.** 계약이 아니다. 사용자 결정(6절)과 AI 방식 개발 측정 결과(3절)를 받은 뒤 계약을 쓰고 Codex 검토를 받는다.
- 배경: D4(공식, [결과](../eval/d4_eval/results/2026-10-20/REPORT.ko.md))는 네 묶음 모두 미충족이었다.
  - AI 방식의 표시 없이 틀린 값 38칸은 모두 "다른 재무제표의 행이 한 시트에 섞인 것"이었다.
  - 표시 없이 틀린 계정명 중 4칸은 AI가 고쳐 쓴 계정명이었다.
  - 결함을 고친 제품은 커밋 `5cdb4e1`이다.
- 원칙(D4 계약 1): 고친 버전을 D4 문서로 다시 잰 것은 개발 측정이고 공식 결과가 아니다. 고친 버전의 공식 결과는 처음 보는 문서로만 낸다.

## 1. D4에서 그대로 가져오는 것

- 계약 7판의 모든 규칙:
  - 지표 S1·L1·S2와 기준
  - 정답 생성기와 매핑표, 사람 판정, 위치 검사(4.6), 공식 집계
  - 실행 기록 관문, 신뢰 경계
- 절차: 고정 → 후보 판정 → 정답·매핑표 확정 → 등록(태그 push) → 실행 → 판정. 작업 폴더·점검 로그·실행 폴더는 저장소 밖에 둔다.
- 도구: `eval/d4_gold.py`, `d4_score.py`, `d4_candidates.py`, `d4_preflight.py`, `d4_scan.py`, `d4_download.py`, `d4_eval/position_check.py`, `official_d4.py`, `run_d4.py`
- 모집단과 순서: `eval/d4_population.json`. 종목코드가 있는 3,998곳을 `sha256("D4-2026|" + 고유번호)` 순으로 정렬한 것이다. D4가 1~19번에서 10곳을 고르고 멈췄으므로, **D5는 20번부터 같은 규칙(D4 계약 3.2)으로 다음 10곳을 고른다.** 순서는 D4 때 이미 고정·공개됐으므로 회사를 고르는 데 재량이 없다.

## 2. D5에서 바꾸는 것 (계약 8판 또는 D5 계약에 적는다)

1. **평가 도구 결함 2건을 고정 전에 고친다.** D4가 새 문서에서 찾은 것이다.
   - 정답 생성기가 띄어 쓴 제목("연결 재무상태표")과 점 날짜 기간 줄("2025.12.31 현재")을 재무제표로 찾지 못했다. D4에서는 DSR의 4개 재무제표를 사람이 옮겨 적었다.
   - 정답 생성기와 채점기의 계정명 비교가 서로 다르다. 정답은 끝의 " :"를 버리고 채점기는 남긴다. 가운뎃점(ㆍ, ·)도 다른 글자로 본다. D4에서는 값이 맞는 10칸이 L1로 세어졌다(공식 결과는 그대로, 두 결과 보고).
   - 고친 도구는 새로 고정한다(T). 고친 뒤에도 D4 기록을 다시 채점해, 바뀌는 칸이 위 10칸뿐인지 확인한다.
2. **판정 기준을 계약에 처음부터 적는다.** 정답 밖 칸은 엑셀에서 재무제표(시트)·계정명·기간 열·금액 넷이 모두 인쇄와 같게 읽히면 ok, 하나라도 틀리거나 알 수 없으면 wrong이다. D4에서는 실행 뒤에 Codex 검토로 이 기준을 바로잡았다.
3. **실행 절차:** D4에서 실제로 쓴 방식을 절차서에 넣는다. 전원 연결을 기다리고 앱과 분리해 실행하는 스크립트다. 점검 명령은 모듈 실행으로 둔다.
4. **"제목 미확인 표"의 채점:** 새 제품은 제목을 못 읽은 표를 따로 두고 모든 칸을 표시한다. 채점기는 이 표를 어느 정답 재무제표와도 짝짓지 않으므로, 그 칸은 정답 밖 칸(표시됨)이 되고 정답 칸은 빠짐이 된다. 빠짐이 가리켜졌는지는 기존 규칙(4.4)을 따른다. 이 처리를 계약에 적는다.

## 3. 개발 측정 (D4 문서, 공식 아님)

- 규칙 방식 (2026-10-20, 끝남):
  - 텍스트 PDF의 맞음 2,225칸은 그대로다. DSR 자본변동표가 따로 분리됐다.
  - 스캔의 표시 없는 정답 밖 칸 3 → 0, L1 2 → 0. 스캔 칸은 모두 표시된다.
  - D4 전의 개발 문서 5개(정답 칸 1,407개)는 수치가 하나도 바뀌지 않았다.
- AI 방식: 진행 중. 결과를 보고 더 고칠 것이 있으면 D5 고정 전에 고친다.
