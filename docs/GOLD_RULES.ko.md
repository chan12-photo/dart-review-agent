# 정답 규칙: 개발용 질문 세트

- 대상: [`eval/dev_questions.json`](../eval/dev_questions.json) (질문과 사람이 지정한 근거), [`eval/dev_gold.json`](../eval/dev_gold.json) (코드가 만든 정답)
- 상태: **초안 (2026-10-07, Claude 작성)**. 사용자 검토와 Codex 검토를 거쳐 확정한다 (로드맵 "Codex 이중 검증 계획"). 개발용이므로 검토 뒤 고칠 수 있다. 최종 평가 세트(3-1)는 따로 만들고 실행 전에 봉인한다.

## 1. 정답을 만드는 방식 (순환 방지)

정답을 1-2의 규칙 코드로 계산하면, 규칙의 버그가 정답에도 그대로 들어가 평가가 버그를 못 잡는다. 그래서 정답은 두 갈래로 만들고 서로 대조한다.

1. **사람이 지정한 근거:** 질문마다 정답이 들어 있는 보고서(연도, 보고서 코드), 칸(`thstrm` 등), 재무제표, 계정ID를 `dev_questions.json`에 직접 적는다. 기대 상태(`비교 가능` 등)와 부호가 바뀌는 경우의 표현(흑자 전환 등)도 적는다.
2. **독립 계산:** [`eval/build_gold.py`](../eval/build_gold.py)는 규칙 모듈(기간 표, 계정 찾기, 비교 규칙)을 쓰지 않는다. 캐시 원본에서 지정된 행을 직접 읽고(재무제표 + 계정ID + 합계 행이 정확히 1개), 변화량과 변화율을 따로 계산한다.
3. **대조:** 같은 질문을 규칙 코드(`review_change`)로도 풀어서 상태, 두 금액, 근거 보고서·칸, 접수번호, 변화량, 변화율, 부호 표현이 모두 같은지 확인한다. 하나라도 다르면 정답 파일을 만들지 않고 멈춘다. 다르면 근거 지정과 규칙 중 어느 쪽이 틀렸는지 조사한다.

이 방식이 막지 못하는 것: 근거를 지정한 사람(지금은 Claude)과 규칙을 만든 사람이 **같은 착각**을 하는 경우. 그래서 독립 검토(사용자, Codex)가 필요하다.

## 2. 질문 해석의 기본값

질문이 말하지 않은 부분은 아래 기본값으로 정한다. Agent도 같은 기본값을 따르고, 답에 어떤 기본값을 썼는지 밝혀야 한다.

| 질문 표현 | 해석 |
|---|---|
| 연결·별도 언급 없음 | **연결** (K-IFRS 주재무제표, 언론·IR의 일반 관행) |
| "N년 매출" (분기 언급 없음) | N년 연간 12개월 (사업보고서) |
| "N년 3분기 매출" | 7~9월 3개월 |
| "3분기 누적", "3분기까지", "1~9월" | 1~9월 누적 |
| "3분기말 자산" | 9월 30일 시점 |
| "전년보다", "작년 같은 분기와", "전년 같은 기간" | 기간 길이와 위치가 같은 전년 기간 |
| 시점 값의 "1년 전" | 전년 같은 날짜 시점 |
| "직전 분기보다" | 바로 앞 분기의 같은 길이 기간 (3개월끼리) |
| "이익"처럼 계정이 둘 이상으로 읽힘 | **되묻는다** (영업이익인지 당기순이익인지) |

## 3. 계산 규칙

- **금액:** 원 단위 정수. 조·억 단위 표시는 출력 단계(2-3)의 일이고, 정답 비교는 원 단위로 한다.
- **기준 값:** 비교 기간 보고서에 기준 기간 칸이 있으면 그 칸을 쓴다(같은 기준으로 작성된 값, 재작성 반영). 없으면 기준 기간의 원래 보고서를 쓴다.
- **변화량:** 비교 값 − 기준 값.
- **변화율:** 기준 값이 0보다 크고 비교 값이 0 이상일 때만 계산한다. (비교 값 − 기준 값) ÷ 기준 값 × 100을 소수 둘째 자리에서 반올림한다(0.005는 올림).
- **부호가 바뀌거나 기준 값이 0 이하:** 변화율을 계산하지 않는다. 영업이익·당기순이익은 흑자 전환, 적자 전환, 적자 축소, 적자 확대로 표현한다.
- **상태:**
  - `비교 가능`: 변화를 계산한다.
  - `비교 불가`: 연결과 별도, 시점과 기간, 다른 기간 길이, 다른 통화, 보고서에 없는 기간(현금흐름 3개월, 4분기 3개월). 이유를 밝히고, 가능하면 비교할 수 있는 대안을 제시한다.
  - `데이터 없음`: OpenDART가 제공하지 않는 기간(2015년 이전 등). 오류와 구분해서 답한다.
  - `확인 필요`: 두 보고서 사이에 재작성이 있어 기준이 다를 수 있는 경우. 숫자는 보여 주되 이 사실을 먼저 밝힌다.
- **연결과 별도를 함께 묻는 질문:** 두 값을 나란히 보여 준다. 둘의 차이나 비율을 "변화"처럼 계산하지 않는다.
