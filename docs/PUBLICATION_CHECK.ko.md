## 2. OpenDART 이용약관 확인

- 출처: opendart.fss.or.kr/intro/terms.do, 2026-10-09 열람. 부칙상 "2020년 1월 21일부터 시행"이다.
- 관련 조항:
  - 제16조 ①: 오픈API 서비스와 관련 프로그램의 저작권은 금융감독원에 있다.
  - 제16조 ④: 약관에 없는 저작권 사항은 저작권법과 공공데이터법을 따른다.
  - 제19조 ②: 인증키를 제3자가 이용하게 해서는 안 된다.
  - 제20조 ② 6호: 인증키를 고의로 유출하면 이용 계약을 해지할 수 있다.
- **재배포, 2차 이용, 상업적 이용, 출처 표시를 직접 정한 조항은 없다.**
- 해석:
  - 제16조 ①이 말하는 대상은 API 서비스와 프로그램이다. 이 저장소는 OpenDART의 프로그램을 담지 않는다. 담는 것은 공시된 재무 수치 일부다.
  - 공시 수치는 회사가 법에 따라 공개한 사실 정보다. 이 저장소는 그중 평가와 데모에 필요한 일부만, 출처를 밝혀 쓴다.
  - 인증키 조항(제19·20조)이 실제로 지켜야 할 핵심이다. 키는 `~/.config/opendart/api_key`에서만 읽고, 기록 전체 검사로 저장소에 없음을 확인했다.
- 조치:
  - README와 `demo/README.md`에 "데이터 출처: 금융감독원 OpenDART (opendart.fss.or.kr)"를 적는다.
  - 원본 응답 전체는 계속 넣지 않는다.
  - 출력이 투자 판단의 근거가 아니라고 적는다.
