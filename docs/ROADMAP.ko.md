1. **시작:** 이 문서의 "현재 상태"와 첫 번째 미완료 작업을 확인한다. 추천 모드를 사용자에게 먼저 알린다.
2. **작업:** 한 번에 작업 하나. 끝나면 완료 기준을 실제로 확인한다(테스트, 실행 결과).
3. **종료:** 상태 표시와 "현재 상태"를 갱신하고 커밋한다. 세션이 중간에 끊겨도 다음 세션이 이어받을 수 있게 남긴다.
4. **push, GitHub 저장소 생성, 공개 전환**은 매번 사용자에게 먼저 묻는다.

## 1단계: 가능성 검증
목표는 "이 문제를 로컬 모델로 풀 수 있는가"를 작은 범위에서 확인하는 것이다. 실패하면 SCOPE 10절의 중단·전환 기준을 따른다.

- [ ] **1-1 OpenDART 클라이언트와 응답 캐시** · 추천 모드: 높음
  - 키는 파일에서만 읽고, 로그·예외 메시지·캐시에 키가 남지 않게 한다.
  - 허용 엔드포인트 목록, 호출 간격, 재시도(일시 오류만), 시간 제한.
  - 응답 상태 코드 분류: `000` 정상, `013` 데이터 없음, 그 외는 오류로 구분.
  - 응답 캐시: 원본 JSON + 받은 시각 + SHA-256. 캐시가 있으면 네트워크를 쓰지 않는다.
  - 공개 안전성 검사(local-agent-lab에서 가져옴)에 `crtfc_key` 패턴 추가.
  - **완료 기준:** 개발용 3곳 × 2023~2025 × (사업·반기·분기) × (연결·별도) 캐시 확보. 키 없이 캐시만으로 테스트 통과. 로그와 캐시에 키 문자열 0건.
- [ ] **1-2 재무 도메인 규칙** · 추천 모드: **엑스트라** (정확성의 핵심)
  - 보고서 종류별 기간 모델:
    - 손익계산서·포괄손익계산서: 3개월 값과 누적 값이 다른 칸에 있음
    - 현금흐름표: "당기" 칸이 이미 누적
    - 재무상태표: 시점 값
  - 비교 가능성 규칙: 같은 연결/별도, 같은 기간 종류, 같은 통화, 0으로 나누기
  - 계정 찾기: 표준계정ID 우선, 없으면 이름 후보 목록(예: 매출 → 매출액 / 영업수익 / 수익(매출액))
  - **완료 기준:** 개발용 3곳의 실제 캐시로 만든 단위 테스트 통과. 함정 4종(SCOPE 5절)에 대한 테스트가 각각 있고, 수정 전 코드에서 실패하는 것을 확인.
- [ ] **1-3 정답 생성기와 개발용 질문 세트** · 추천 모드: **엑스트라**
  - 질문 10~12개는 사람이 쓴다(SCOPE 7절의 사례 유형을 하나 이상씩 포함).
  - 정답(숫자, 기준, 상태)은 캐시 원본에서 코드로 계산한다.
  - **완료 기준:** 모든 질문의 정답이 원본 값과 일치하는지 자동 확인. 질문과 정답 규칙을 커밋.
- [ ] **1-4 평가 실행기 (세 가지 방식)** · 추천 모드: 높음
  - ① 규칙만 ② 정답 근거를 모델에 직접 제공 ③ 전체 흐름(도구 호출 포함, 1차 버전)
  - 지표: 숫자 일치, 기준 정확도, 거절·되묻기 정확도, 근거 없는 숫자, 요청 수, 지연
  - **완료 기준:** 가짜 모델 응답으로 채점기 테스트 통과(맞는 답, 틀린 숫자, 기준 혼동, 근거 없는 숫자를 각각 구분).
- [ ] **1-5 gpt-oss:20b로 가능성 검증 실행과 판정** · 추천 모드: 실행은 중간, 판정은 **엑스트라**
  - Ollama는 로컬 전용으로 켜고, 이번 작업에서 켠 프로세스만 끈다.
  - **완료 기준:** 보고서 `eval/feasibility_<날짜>/REPORT.md`. SCOPE 10절 기준(도구·규칙 100%, 근거 제공 시 80% 이상, 근거 없는 숫자 0건)으로 진행 또는 전환을 판정.

## 위험이 현실이 되었을 때
| 상황 | 대응 |
|---|---|
| OpenDART 응답이 불안정하거나 호출 제한에 걸림 | 캐시 우선, 호출 간격 확대, 원인 기록. 계속되면 범위 축소 |
| 근거 제공 평가가 60% 미만 | 모델 병목. 상용 API 비교를 사용자에게 제안(승인 필요) |
| Agent가 기준선을 이기지 못함 | "검증 도구 + LLM 설명"으로 정직하게 재정의 |
| 계정 6개도 안정적으로 못 맞춤 | 회사 또는 계정 축소, 원인을 보고서에 기록 |
| 세션이 작업 중간에 끊김 | 이 문서의 상태 표시와 "현재 상태"를 기준으로 이어서 진행 |
