# Codex 검토(1-5 실행 전) — 중간에 멈춘 기록

- 2026-10-07. Codex가 [요청문](1-5_codex_request.ko.md)으로 검토하던 중 사용량 한도로 약 5분 30초 만에 멈췄다. 결과 파일은 남지 않았고, 저장소 파일은 바뀌지 않았다. 아래는 사용자가 옮겨 준 마지막 메시지의 요지다.
- Codex는 Ollama를 호출하지 않고 가짜 답으로 오탐·미탐, 실행 중단, 기록 누락을 확인하고 있었다.

## 남긴 발견 3개와 처리

| 발견 | Claude 재현 | 처리 |
|---|---|---|
| 실제 금액 `32735035000000`원(쉼표 없음)이 접수번호로 오인돼 탈락 | 재현됨 | 14자리 숫자는 허용 접수번호이거나 정확히 같은 허용 금액이면 근거 있음 |
| 근거가 10.88%인데 "10.88배"라고 써도 통과 | 재현됨 | 배수와 퍼센트포인트는 변화율로 근거가 되지 않게 분리. 같은 종류로 `10.88%p`도 통과하던 것을 Claude가 찾아 함께 고침 |
| 시점 값의 시작 날짜를 일부만 잘못 쓴 답에서 채점기 예외 | 재현됨 (None과 날짜 문자열을 함께 정렬하다 TypeError) | 정렬 키에서 None 처리. 기준 오류로 채점됨 |

Claude가 같은 종류로 더 찾은 것: 도구 호출의 `function`이 객체가 아니면 실행기가 예외를 냄 → 오류 결과로 처리.

회귀 테스트와, 형식이 맞는 무작위 답 500개 × 13문항으로 채점기가 예외를 내지 않는지 보는 테스트를 추가했다(옛 정렬로 되돌리면 이 테스트가 실패하는 것도 확인).
