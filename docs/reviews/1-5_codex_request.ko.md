## 요청문

이 저장소의 평가 실행기와 채점 규칙을 **모델을 실제로 돌리기 전에** 독립적으로 검토해 줘. 다음 단계(1-5)에서 로컬 gpt-oss:20b로 개발용 13문항을 돌리고, 그 점수로 "계속 진행 / 방향 전환"을 판정한다. 채점이 너무 느슨하면 나쁜 모델이 통과하고, 너무 엄격하거나 오탐이 있으면 좋은 답이 떨어진다. 둘 다 찾아 줘.

**지킬 것**
- `AGENTS.md`를 따른다. 인증키 파일을 열지 않고, API와 Ollama를 호출하지 않고, 추적 파일을 수정하지 않는다.
- 근거는 실행한 명령과 결과, 또는 직접 만든 가짜 답으로 보여 준다. 칭찬은 필요 없다.

**읽을 것**
- 설계: `docs/EVAL_DESIGN.ko.md` (이 문서가 계약이다), `docs/GOLD_RULES.ko.md`
- 코드: `eval/scoring.py`, `dart_review/numbers.py`, `eval/run_eval.py`, `dart_review/answer.py`, `dart_review/tools.py`, `dart_review/prompts.py`, `dart_review/llm.py`
- 정답: `eval/dev_gold.json`, `eval/dev_questions.json`
- 테스트: `tests/test_scoring.py`, `tests/test_numbers.py`, `tests/test_run_eval.py`, `tests/test_llm_answer_tools.py`

**검토할 것**
1. **설계와 코드의 일치:** `EVAL_DESIGN.ko.md`의 3~5절이 `scoring.py`와 `numbers.py`에 그대로 구현됐는가. 문서에 있는데 코드에 없거나, 코드에만 있는 규칙을 찾아 줘.
2. **근거 없는 숫자 판정:** 그럴듯한 한국어 답을 직접 여러 개 만들어 보고 다음을 찾아 줘.
   - 근거가 있는데 근거 없다고 나오는 경우(오탐). 예: 흔한 금액·날짜·기간 표기, "1조 2천억", "약 3,276억", "3.3조", "전년 대비 6.6%p"
   - 근거가 없는데 통과하는 경우(미탐). 예: 허용 오차를 악용한 숫자, 스스로 계산한 숫자가 우연히 다른 허용 숫자와 가까운 경우
   - 표시 자리 단위 안에서 반올림·버림을 모두 인정하는 규칙이 너무 느슨한지
3. **문항별 채점의 공정성:** 13문항 각각에 대해, 올바른 답인데 떨어지는 경우나 틀린 답인데 통과하는 경우가 있는가. 특히 다음.
   - dev05: `나란히 표시`와 `change=null` 요구
   - dev08: `확인 필요`의 이유를 단정적으로 써도 통과하는 문제(자동 판정 안 함, 한계로 기록함)
   - dev10: 대안 제시를 채점하지 않음
   - dev12: 되묻기 질문에 두 후보 이름이 모두 있어야 함
   - 시점 값의 `start=null` 요구
4. **세 가지 방식의 설계:** ②에서 원본 행이 아니라 도구 결과를 주기로 한 결정(EVAL_DESIGN 1절)이 SCOPE 7절의 목적(실패 원인 분리)에 맞는가. ②에서 dev12에 두 후보 결과를 모두 주는 방식이 공정한가. ③의 예산(모델 5회, 도구 3회)과 실패 처리가 합리적인가.
5. **1-3 반영분 재확인(선택):** 네가 1-3 검토 부록 B로 재현한 R1~R5가 지금 코드에서 막혔는가. `dart_review/review.py`의 새 재작성 확인(보고서 연결, "누적 − 3개월" 파생값)이 엉뚱한 연결을 만들 수 있는가.
6. **1-5 실행 조건:** 프롬프트(`prompts.py`)가 정답이나 채점 규칙을 부당하게 흘리지 않는가(예: 질문별 힌트). Ollama 옵션(`num_ctx` 8192, `num_predict` 4096, `temperature` 0, `think` 미지정)과 기록 항목이 재현과 보고에 충분한가.

**답의 형식**
- 발견 사항마다: 심각도(치명 / 중요 / 사소), 위치(파일:줄 또는 문항 ID), 근거(실행한 명령, 만든 가짜 답과 채점 결과), 제안
- 1-5 실행 전에 꼭 고쳐야 할 것과 실행 후에 고쳐도 되는 것을 나눠 적기
- 직접 확인한 것과 확인하지 못한 것을 구분해 적기
