## 요청문

`AGENTS.md`를 따른다. 인증키, OpenDART API, Ollama는 쓰지 않는다. 3-5 평가는 끝났으므로 `eval/template_3-5/`의 기록과 로컬 캐시는 읽어도 된다. 그러나 실행을 다시 하거나, 기록·검토·판정 파일을 고치거나, 공식 판정을 다시 내지 않는다. 메모리 안에서 다시 채점해 대조하는 것은 괜찮다.

추적 파일은 수정하지 말고, 결과는 `docs/reviews/3-5_report_codex_result.ko.md`에만 써 줘. 칭찬은 필요 없다. 틀렸거나, 근거가 약하거나, 결과를 실제보다 좋게 보이게 하는 것만 적어 줘. 발견마다 다음을 적고, "공개 전에 고칠 것"과 "기록만 할 것"을 나눠 줘.
- 심각도(치명/중요/사소)
- 위치(파일:줄)
- 근거(명령과 결과)
- 제안
