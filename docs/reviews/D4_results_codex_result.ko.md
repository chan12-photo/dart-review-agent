- **가장 작은 수정:** 계약 4.3·4.5를 함께 적용해 “다른 재무제표 시트에 배치된 인쇄값”의 판정을 확정한다. `wrong`으로 고치면 계약 6절대로 **27개 id 전부의 변경 이력, 이전/새 집계와 판정**을 함께 남긴다. `ok`를 유지한다면 재무제표 종류의 오류를 S1에서 제외한다는 명시적 해석과 AI 3.3의 반대 판정을 공식 주장 바로 옆에 적는다. 어느 쪽이든 정답·제품·등록 기록을 사후에 고치지 말고, README 갱신과 결과 push 전에 해결한다.

## 직접 확인하지 않은 것
