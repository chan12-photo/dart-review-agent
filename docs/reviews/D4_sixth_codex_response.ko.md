# D4 6차 검토(Codex)에 대한 응답 (2026-10-15)

- 대상: `docs/reviews/D4_sixth_codex_result.ko.md` (기준 `5d8cbd6`). 결과 파일은 이 응답과 같은 커밋에 그대로 넣었다.
- **결론: ④ 고정 전에 고칠 것 1건을 고쳤고, 기록 2건도 처리했다.** 5차 1·5·6번 수정은 Codex가 반례로 다시 확인했다.

## 1. ④ 고정 전에 고칠 것

| # | 처리 |
|---|---|
| 1 `no_unit=ignore`로 숫자 표 전체가 정답에서 빠져도 공식 판정 가능 | 5차 1번과 같은 종류를 다른 항목에서 놓친 것이다(Claude의 실수). 항목 하나만 막지 않고 **일반 규칙**으로 고쳤다. 매핑을 적용한 뒤 인쇄된 정답 칸이 하나도 없는 재무제표가 있으면, 어떤 결정으로 그렇게 됐든 그 문서는 `unscorable`이다(`eval/d4_gold.py apply_mapping`). 시험: 단위 없는 표의 `no_unit`을 `ignore`하면 `scorable=false`, `add`하면 판정 가능. 이 시험은 고치기 전 코드에서 실패한다. 개발 문서 10개 점수(5개 × 두 방식)는 다시 채점해도 같고, 판정 불가가 된 문서는 없다 |

## 2. 기록만 할 것

| # | 처리 |
|---|---|
| 1 등록 때 매핑표 상태 검사가 파일 이름에만 기댐 | 코드와 계약을 함께 고쳤다. `register`는 이름이 `.mapping.json`이거나 내용에 `decisions`가 있는 파일을 매핑표로 보고 `confirmed`를 요구한다. 다른 이름의 `draft` 매핑표를 거부하는 시험을 넣었다 |
| 2 근거 내용은 기계로 검사하지 않음 | 계약 4.2에 "도구는 근거가 비어 있지 않고 서로 다른지만 확인하고, 실제 쪽·줄·계산과 맞는지는 사람이 확인한다"를 적었다 |

## 3. 다음
