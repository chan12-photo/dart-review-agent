### 4. [중요] 안전 검사 도구는 발견한 일부 비밀값을 그대로 출력하고, 0건의 범위가 좁다

### B. 예시 질문·공개 데이터

`--no-model --cache cache --offline --reference-date 2026-10-08`로 기능 표의 예시 8개를 실행했고 모두 종료 0이었다. 상태는 순서대로 **값 확인, 비교 가능, 나란히 표시, 되묻기, 되묻기, 범위 밖, 범위 밖, 데이터 없음**이다. 카카오 비교 예시는 변화량 `-90,073,719,206원`, 변화율 `-4.48%`였다. 답 종류는 표와 맞지만 첫 예시의 재작성 대조 문구는 1번처럼 다르다.

현재 추적 파일 280개를 목록과 구조로 확인했다. `demo/opendart/`는 응답 6개(본문·메타 12파일), 본문 합계 **73행**이며 원본 보고서 수백 행 전체는 포함하지 않는다. `dart_review/company_vocabulary*.json`의 이름 수 **302·264**, `account_vocabulary.json` **472**, `fetch_manifest.json.entries` **152**도 문서 3절과 일치한다. 로컬 캐시의 `corpCode.xml` 원본 목록 **119,558개**도 직접 세어 확인했다. 추적 파일에 `corpCode.xml` 원본·ZIP·SQLite·`cache/` 경로는 없고, 구조화된 JSON/JSONL에서 20개를 넘는 계정 행 배열도 찾지 못했다. `demo/opendart/`의 실제 파일 바이트 합계는 **38,143 B**, macOS `du -sk`의 할당 디스크 크기는 **68 KiB**다. 문서의 “68KB”는 할당 크기 기준으로 해석하면 맞지만 파일 바이트 크기로 읽히지 않도록 단위를 밝히면 좋다.

### C. CI·빠른 시작 재현 범위

새 임시 로컬 클론을 만들고 빈 `HOME`, 키 파일 없음, `cache/` 없음, `DART_API_KEY_FILE=/nonexistent` 조건에서 CI의 네 명령을 실행했다: 단위 테스트 **279건 통과(82건 건너뜀)**, 데모 정상(네트워크 0회), 현재 파일 안전 검사 0건, Git 이력 안전 검사 0건. 이 재현은 **Python 3.14.7**에서 수행했다. 저장소의 Python 파일 60개를 `ast.parse(feature_version=(3,10))`로 구문 검사했으며 오류는 없었다. Mac에는 Python 3.10·3.12 실행 파일이 없어 그 버전의 런타임 테스트와 실제 GitHub Actions 첫 실행은 **직접 확인하지 못했다**. `pyproject.toml`은 `>=3.10`, 외부 런타임 의존성 없음으로 선언한다. GitHub의 [checkout 문서](https://github.com/actions/checkout/blob/main/README.md)는 `fetch-depth: 0`이 전체 이력을 가져오는 설정이라고 설명하며, [setup-python의 공식 테스트](https://github.com/actions/setup-python/blob/main/.github/workflows/test-python.yml)는 3.10·3.12를 포함한다. 원격 CI 결과가 나오기 전에는 “3.10·3.12에서 통과했다”고 쓰지 않는다.

현재 README의 첫 세 빠른 시작 명령은 이 Mac에서 종료 0이었다. 다만 세 번째 무연도 질문은 5번처럼 날짜가 바뀌면 같은 데모 자료에서 답하지 못한다. 인증키를 쓰는 두 번째 시작 절차(`fetch_dev_cache.py`, 기본 모델 `gpt-oss:20b`)는 사용자 금지 범위에 속하므로 **실행하지 않았고**, 키·Ollama가 준비된 새 사용자 환경에서 바로 동작한다고 보증하지 않는다.
