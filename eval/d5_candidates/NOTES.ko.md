# D5 평가 후보 기록 메모

- **20~30번:** `eval/d4_candidates/`의 D4 기록을 복사했다(사용자 결정 2026-10-21, 재사용). 각 파일의 `copied_from`에 원본 경로, git 객체, 복사한 커밋, 받은 시각, 뺀 항목(D4의 첨부 이름)을 적었다. D4 파일은 고치지 않았다.
- **31~40번:** 2026-10-21에 OpenDART에서 새로 받았다(사용자 승인, 기업개황 `company.json`과 공시 목록 `list.json`, 요청 20회).
  - 받은 도구는 `eval/d4_population.py`의 `fetch` 함수다. 모집단 순서를 31~40번으로 잘라서 넘겼다. 그대로 쓰면 1번부터 다시 훑어 1~19번 가운데 제외 목록에 없는 회사까지 조회하기 때문이다. 도구 파일은 바꾸지 않았다.
  - 제외 목록은 `eval/d5_excluded.json`, 캐시는 `cache/d4`(git 제외)다.
  - 쓴 코드:

    ```python
    cut = {**population, "order": [e for e in population["order"] if 31 <= e["rank"] <= 40]}
    fetch(DartClient(ResponseCache(ROOT / "cache" / "d4")), cut, excluded, Path("eval/d5_candidates"), 10)
    ```
